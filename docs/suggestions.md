# Proposed improvements

These are suggestions only. They are not implemented or scheduled by the 0.2.1 changes.

| Priority | Suggestion | Practical benefit | Platform |
| --- | --- | --- | --- |
| 1 | A battle review screen for uncertain SAM events | Group a disappearance and a matching HUD event, show the evidence, and let the player confirm or reject it after the engagement. | Windows and web |
| 2 | Optional local session recording and replay | Rewind the last few minutes to understand a lost contact, a route or a SAM restoration. Include retention limits and an explicit recording control. | Windows and web |
| 3 | Saved aircraft and control profiles | Save preferred marker size, trail length, threat distance and overlay layout per aircraft or play style. | Windows and web |
| 4 | Configurable sound alerts | Announce a newly observed nuclear aircraft or a nearby threat with adjustable volume, cooldowns and quiet mode. Keep uncertain and manual evidence distinguishable. | Windows and web, subject to browser audio permission |
| 5 | Threat-aware route timing | Add estimated arrival times and fuel/time tradeoffs using a chosen cruise speed, with clear uncertainty for moving threats. | Windows and web |
| 6 | A second-monitor dashboard | Offer a compact view of nearby threats, selected targets and mission changes while keeping the full map on another screen. | Windows and web |
| 7 | A data-update comparison screen | Show which SAM models, ranges or positions changed in a downloaded pack and provide a deliberate rollback control. | Windows; change history on web |
| 8 | More accessible visual presets | Add color-vision presets, contrast adjustments and shape-based team markers so critical states do not depend on red/blue alone. | Windows and web |

Suggested order: improve review of uncertain events first, then add local replay and saved profiles. Those features would make the current live map easier to verify and use before adding more alerts.
